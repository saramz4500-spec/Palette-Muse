# Palette-Muse
:

🎨 Palette Muse

A color palette generator that helps users create harmonious color combinations using an external API.

🚀 Features
Generate color palettes
Choose different color modes
Copy colors or full palette
Save and clear palettes
Live preview
Export CSS
🛠️ Technologies
HTML
CSS
JavaScript
Fetch API
🌐 API

https://www.thecolorapi.com/

▶️ How to Use
Select a color
Choose a mode
Click Generate
Copy or save the palette
